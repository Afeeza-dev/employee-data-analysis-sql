# Employee Data Analysis Using SQL

## Project Overview

This project demonstrates SQL-based analysis on an employee dataset using MySQL.

## Dataset Columns

* EMP_ID
* NAME
* GENDER
* DEPT
* SALARY
* CITY
* EXP
* JOINING_YEAR

## SQL Operations Performed

* SELECT
* WHERE
* GROUP BY
* COUNT()
* AVG()
* ORDER BY
* DESCRIBE

## Project Objectives

* Create and manage a database
* Import CSV data into MySQL
* Perform data analysis using SQL queries
* Generate business insights from employee records

## Tools Used

* MySQL Workbench
* Microsoft Excel
* GitHub
